# Blink Twice EyeRest — v1.6.0

> Released: July 2026
> Builds on **v1.5.1** — https://github.com/rockyway/eye-rest/releases/tag/v1.5.1

Blink Twice EyeRest runs on **Windows, macOS, and Linux**. Items below note the platform when a
change applies to only one.

---

## What's New

### ⏱ Automatic Breaks — now optional

- New **Automatic Breaks** toggle in settings — turn the longer break reminder off completely and
  keep only the 20-20-20 eye rest reminders
- Ideal if you already take your own breaks and just want the eye reminders, or if longer
  full-screen breaks don't suit how you work
- When the toggle is off, the Work Interval and Break Duration settings grey out, so it's always
  clear which reminders are actually running
- Your eye rest reminders carry on exactly as before — only the break timer stops
- You can still start a break yourself at any time with **Break Now**

---

## Fixes & Improvements

### 🖥 Popups

- **Reminder popups no longer appear cut off on multi-monitor setups** — if your displays use
  different scaling levels (for example 100% on one monitor and 150% on another), a popup could
  show up sized for the wrong monitor, clipping the title and buttons off the edges. Popups now
  resize correctly for whichever display they appear on.

---

## Install & Update

- **New install:** download for your platform from the release assets below — Windows
  (`EyeRest-win-Setup.exe`), macOS (`EyeRest-osx-Portable.zip`), Linux (`EyeRest.AppImage`) — or
  from https://eyerest.net.
- **Existing users:** the app updates itself — open **About → Check for Updates**, or it updates
  silently on next launch.
